# About this Project
This project was created as a web development project to practice building a multi-page website using HTML and CSS, for the sake of my Grade 13 Digital Media Unit 2 Internal Assessment Project.


# Project Overview
The GamerTingz website is designed around the idea of creating an online platform for gamers. The website provides access to different sections including gaming courses, a community, competitions, donations, and user accounts.

The homepage introduces the GamerTingz platform through a combination of custom layouts, images, typography, navigation elements, embedded media, and descriptive content.

# Design

The website uses a gaming-oriented visual style with custom typography, graphics, navigation elements, and promotional content.

Different Google Fonts were experimented with throughout the project to create distinct visual styles for headings, navigation, and body content.

# Purpose

The main purpose of GamerTingz was to explore how a larger website could be planned and structured using fundamental HTML and CSS concepts.

Rather than being a fully functional gaming platform, this project represents the frontend design and structure of a gaming website concept.
